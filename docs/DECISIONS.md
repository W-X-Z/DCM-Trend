| AI 사용 범위 | 계산은 SQL, AI 는 계산 결과를 문장으로만. 사실에 없는 숫자·전망 표현은 자동으로 걸러 규칙 문장으로 대체. OpenAI 키는 GitHub Secrets 에만 둠 |

| 만기도래 기본값 | 3~6개월 뒤, 금융사 제외(토글로 포함) |
| 과거 회사채 백필 | 회사 미지정 공시검색은 파생결합증권까지 받아 비쌈 → 공모채 이력·잔액이 있는 회사만 회사별 검색 (2019~) |
| 원문 저장 | 무료 DB 용량 때문에 원문 전체는 저장하지 않고 뽑은 값만 `raw.doc_fields` 에 저장 |
| 로직 개선 방식 | 현업 인터뷰 후 `ref` 행·`mart` SQL 수정 (docs/LOGIC_CHANGE_GUIDE.md) |
| 원문 값 병합 (10-15) | 한 딜의 수요예측·가산금리(첫 발행조건확정)와 확정 금리(기준금리 확정 공시)가 나뉘어 있어, 필드마다 딜의 가장 최근 공시 값을 쓴다. 파서를 고치면 `ref.document_fetch_rules.parser_version` 을 올려 다시 읽는다 |
| 인사이트 보정 (10-15) | 금액 합계가 한 건에 좌우될 때(예: 26.07~09 유상증자 48.8조 중 SK하이닉스 ADR 40조) '최대 1건 비중'·'최대 1건 제외 금액'과 딜 이름을 함께 보여 준다. 신주 비율은 중간값 |

| 서비스 이름 (10-15) | 'DCM 트렌드' → '발행시장 트렌드' |
| AI 역할 (10-15 개편) | 지표 변화는 SQL 값을 막대 타일로 그대로 보여 주고 AI 문장은 쓰지 않는다. AI 는 '눈여겨볼 회사'만 고른다: 규칙(`ref.signal_rules`)이 공시·발행·만기·차입 잔액에서 후보를 뽑으면 AI 가 6곳 안팎을 골라 근거·대화 소재를 한 줄씩 쓴다. 후보 밖 회사·후보 수치에 없는 숫자는 버리고 모자라면 규칙 순서로 채운다 |
| 화면 문구 (10-15) | 설명 문구는 화면에 늘어놓지 않고 제목 옆 '?' 툴팁으로. 상품(회사채·메자닌·유상증자·IPO)은 머리글이 아니라 동향 화면 안 탭으로 |
| 금리 데이터 (10-15) | ECOS 인증키 대신 예약 작업(평일 18:25 KST)이 장 마감 기사·공개 자료에서 금리를 조사해 출처와 함께 넣는다(`ingest_put_rates_research`). ECOS 키를 등록하면 그 값이 우선한다. 조사 값은 국고채 3·10년 위주이고 과거 시계열은 조사 시작일부터 쌓인다 |
| 금리 출처 제한 (10-16) | 언론 장 마감 기사·한국은행·금융투자협회 자료만 쓴다. 원 출처가 없는 자동 생성 집계 사이트(시세.com, supple.kr)는 `ref.rate_source_blocklist` 로 막는다. 이미 들어간 값은 지우지 않고 화면(`core.v_rates_valid`)에서 뺀다. 과거 12개월은 월말 값으로 채운다 |
| 화면 구조 (10-16) | 머리글 1줄: 서비스 이름 + 회사 검색(입력 즉시 후보, '/' 키), 2줄: 홈·발행 동향·만기도래·금리·AI 질문 탭 |
| 홈 피드 (10-16) | 최근 14일 이례적 발행(미달·2배 증액·첫 공모채·장기물·BBB·가산금리 +30bp·대형/공모 메자닌·밴드 밖 IPO 등)과 주요 공시(합병·분할·양수도·지분 인수·감자·회생·영업정지·해산)를 `ref.feed_rules` 점수로 뽑고 AI 가 10장 안팎 카드로 쓴다. 공시는 OpenDART 상세 API 값(`ref.detail_field_labels`)을 붙인다. 후보에 없는 숫자가 들어간 카드는 버리고 규칙 문장으로 채운다 |
| 눈여겨볼 회사 (10-16) | '다가오는 영업 접점'으로 이름을 바꾸고 만기·풋·단기 차입 신호만 남김(사건형 신호는 피드로) |
| 발행 동향 (10-16) | 선택 기간 지표·월별 추이를 한 덩어리로, '최근 3개월 변화'는 그 아래 별도 구획. 회사채는 트랜치 묶음(`mart.v_bond_issues`)으로 만기 구간·조합·등급별 대표 구조와 최근 발행을 보여 준다 |
| AI 질문 (10-16) | OpenAI 함수 호출로 mart 읽기 전용 조회 10종만 부른다(모델이 SQL 을 쓰지 않음). 파일 검색(벡터 스토어)은 증권신고서 본문 검색이 필요해질 때 2단계로. 공개 사이트라 IP 당 10분 8회, 다른 사이트 호출 차단 |

## 데이터 범위의 알려진 한계 (10-15 점검)

| 항목 | 내용 |
|---|---|
| 일괄신고 채무증권 | 은행·카드·캐피탈·금융지주·발전 자회사가 쓰는 `일괄신고추가서류` 는 수집하지 않는다. 금감원 '일반회사채' 집계(26.07 2.78조)보다 우리 일반회사채 합계(같은 달 1.13조)가 작은 주된 이유. 금융채·공기업 만기도 일부만 보인다 |
| IPO 의무보유 확약 비율 | 확약기간별 참여내역 표를 합산해야 해서 아직 읽지 않는다 |
| 원천 입력 오류 | 신고서 납입일 칸에 만기일을 적은 회사채는 청약일로 보정 (`core.apply_sanity_fixes`) |
| 메자닌 납입 연기 | 결의 후 납입일이 수년 미뤄진 딜이 있다(정정 공시 기준 그대로 표시) |
