| PPTX 템플릿 (10-23) | PPTX 는 NH 원본 슬라이드 마스터·레이아웃(`web/public/deck/nh-template.pptx`, 대한항공 제안서에서 마스터·레이아웃·고정 장표 9장만 남김)에 장표를 끼워 넣는다(`web/lib/deck/assemble.ts`). 데이터 장표는 pptxgenjs 로 내용만 만들고 머리띠·로고·쪽번호는 레이아웃이 그린다. 고정 장표는 원본 XML 을 쓰고 제목 번호와 `{{발행사}}`·`{{부서}}`·`{{등급}}` 자리 표시만 바꾼다(템플릿 파일에 고객사 이름 없음). 미리보기·PDF 는 레이아웃을 렌더링한 그림(`public/deck/layout`)과 고정 장표 그림(`public/deck/static`, 회사명은 '발행사'로 일반화) 위에 같은 표시 목록을 그린다. 표 칸 바탕은 늘 명시(템플릿 기본 표 스타일 색 방지), 장표 안 도형 id 는 다시 매김 |
| 금통위·FOMC·미국 금리 전망 (10-23) | 직전 회의 핵심 포인트를 결정문·기자회견·보도에서 사람이 요약해 `ref.policy_meetings` 에 넣는다(출처 URL 포함, 원문 인용 아님). 증권사별 미국 기준금리 전망은 `ref.research_views` 에 `region='US'` 로 넣고, 연말·최종 금리는 기사에 수준이 나온 경우만 채운다(추정 금지) |
| 제안서 상세 (10-23) | 대한항공 원본 수준으로 장표를 채운다. 공시로 가능한 것은 자동: 결정조건(확정 가산금리), 국고 대비 스프레드(수요예측일 같은 만기 국고채), **투자자 구분별 수요예측 참여**(정정신고서 참여 내역, 파서 v4), 증액 한도(증권신고서), 노치별 만기도래·분기 소계, 노치별 평균 경쟁률. 공개 자료로 넣는 것: FOMC SEP·점도표, 한은 경제전망·점도표, 한·미 정책금리 이력, 소비자물가 발표일, NH 리서치 주제별 의견(출처 URL). **배정 내역은 증권발행실적보고서에도 기관 합계만 있어 공시로 구할 수 없고**, 개별·등급민평(민평 4사 유료), 기관별 참여, NH 내부 전망표는 '내부 자료 붙여넣기'(엑셀 표 복사, 브라우저에만 저장, AI 로 보내지 않음)로 넣는다 |
| 제안 판단 문장 (10-23) | 원본처럼 줄마다 '근거 → NH 판단'으로 쓴다. 규칙 문안이 근거 숫자(만기별 평균 경쟁률, 참여 기관 구성, 확정 가산금리, 만기도래 연도, 금통위 전후 국고채 변동폭 등)로 판단 문장을 만들고, AI 는 같은 사실 묶음으로 다듬는다. 검증은 숫자가 사실 묶음에 있어야 하고, 금리·스프레드·수요의 **방향을 예측하는 문장은 출처(하우스·한은·연준)를 밝힐 때만** 허용, 확실·보장 표현은 금지 |
| 일별 금리 (10-23) | 금리 동향 차트(국고 2·3년 + 韓·美 기준금리, 2년 일별)와 금통위 전후 변동성 분석은 ECOS 일별 금리가 있어야 한다. GitHub 저장소 secret `ECOS_API_KEY` 를 넣으면 매일 수집되고, 없으면 조사 값(월 1~3회) 월말 차트로 대신한다 |
| 제안서 노하우 (10-24) | 현업 암묵지는 시스템 프롬프트와 따로 `ops.deck_knowledge` 에 둔다(화면 `/proposal/knowledge`). 장표·유형(판단 기준·관행·표현·주의)·적용 등급으로 나누고, '노하우 반영(AI)'이 회사 등급·켠 장표에 맞는 것만 지침으로 넣는다. 프롬프트에는 깨면 안 되는 규칙(숫자 출처, 예측은 출처 인용, 실명 금지)만 남기고 문체 예시·일정 관행은 노하우로 옮겼다. 프로토타입이라 권한 없이 누구나 고치고, 모든 변경을 이력에 남기며 삭제는 숨김(되살리기 가능). 노하우 속 숫자는 문안에 써도 검증을 통과한다. 사외 사이트라 고객사 비공개 정보는 적지 않는다 |

## 데이터 범위의 알려진 한계 (10-15 점검)

| 항목 | 내용 |
|---|---|
| 일괄신고 채무증권 | 은행·카드·캐피탈·금융지주·발전 자회사가 쓰는 `일괄신고추가서류` 는 수집하지 않는다. 금감원 '일반회사채' 집계(26.07 2.78조)보다 우리 일반회사채 합계(같은 달 1.13조)가 작은 주된 이유. 금융채·공기업 만기도 일부만 보인다 |
