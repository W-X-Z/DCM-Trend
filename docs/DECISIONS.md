# 결정 사항

## 결정됨 (2026-10-15)

| 항목 | 결정 |
|---|---|
| 타깃 사용자 | 커버리지 본부 RA·RM |
| 기능 | ① 회사명 → 관련 자료 ② 딜 유형별 최근 트렌드 |
| 상품 | 회사채 공모, 메자닌(CB·BW·EB), 유상증자 |
| 데이터 | OpenDART 공개 데이터. 수요예측 실명 데이터는 후속 개발 요건 |
| 제공 형태 | 웹 서비스 (Next.js on Vercel) |
| DB | Supabase Postgres — 프로젝트 `dcm-trend` (서울 리전, Postgres 17). 기존 jaejallo 프로젝트는 일시정지로 자리 확보 |
| 레포 | github.com/W-X-Z/DCM-Trend |
| 화면 호스팅 | Vercel, 함수 리전 서울(icn1). Supabase 키는 서버 환경변수로만 사용 |
| 수집 | GitHub Actions 매일 07:10 KST. 최초 백필 2024-10-01부터 |
| 2단계 기능 (10-15) | 만기도래(공모채 만기·메자닌 풋·사모·CP·전단채 잔액), 인사이트(규칙 계산 + AI 요약), 금리(지표·금통위 일정, 예측 없음), 주요공시, IPO |
| AI 사용 범위 | 계산은 SQL, AI 는 계산 결과를 문장으로만. 사실에 없는 숫자·전망 표현은 자동으로 걸러 규칙 문장으로 대체. OpenAI 키는 GitHub Secrets 에만 둠 |
| 금리 전망 | 예측 문장 없이 지표·변화폭·금통위 일정만 |
| 만기도래 기본값 | 3~6개월 뒤, 금융사 제외(토글로 포함) |
| 과거 회사채 백필 | 회사 미지정 공시검색은 파생결합증권까지 받아 비쌈 → 공모채 이력·잔액이 있는 회사만 회사별 검색 (2019~) |
| 원문 저장 | 무료 DB 용량 때문에 원문 전체는 저장하지 않고 뽑은 값만 `raw.doc_fields` 에 저장 |
| 로직 개선 방식 | 현업 인터뷰 후 `ref` 행·`mart` SQL 수정 (docs/LOGIC_CHANGE_GUIDE.md) |
| 원문 값 병합 (10-15) | 한 딜의 수요예측·가산금리(첫 발행조건확정)와 확정 금리(기준금리 확정 공시)가 나뉘어 있어, 필드마다 딜의 가장 최근 공시 값을 쓴다. 파서를 고치면 `ref.document_fetch_rules.parser_version` 을 올려 다시 읽는다 |
| 인사이트 보정 (10-15) | 금액 합계가 한 건에 좌우될 때(예: 26.07~09 유상증자 48.8조 중 SK하이닉스 ADR 40조) '최대 1건 비중'·'최대 1건 제외 금액'과 딜 이름을 함께 보여 준다. 신주 비율은 중간값 |

## 데이터 범위의 알려진 한계 (10-15 점검)

| 항목 | 내용 |
|---|---|
| 일괄신고 채무증권 | 은행·카드·캐피탈·금융지주·발전 자회사가 쓰는 `일괄신고추가서류` 는 수집하지 않는다. 금감원 '일반회사채' 집계(26.07 2.78조)보다 우리 일반회사채 합계(같은 달 1.13조)가 작은 주된 이유. 금융채·공기업 만기도 일부만 보인다 |
| IPO 의무보유 확약 비율 | 확약기간별 참여내역 표를 합산해야 해서 아직 읽지 않는다 |
| 원천 입력 오류 | 신고서 납입일 칸에 만기일을 적은 회사채는 청약일로 보정 (`core.apply_sanity_fixes`) |
| 메자닌 납입 연기 | 결의 후 납입일이 수년 미뤄진 딜이 있다(정정 공시 기준 그대로 표시) |

## 결정 대기

| 항목 | 선택지 | 추천 | 비고 |
|---|---|---|---|
| Supabase 플랜 | 무료 유지 / Pro 전환 | MVP는 무료, 현업 시범 시 Pro 검토 | 무료 프로젝트는 7일 저활동 시 자동 정지 → 매일 수집이 돌면 유지됨 |
| Vercel 플랜 | Hobby / Pro | 현업 시범 전 Pro | Hobby 는 비상업적 개인 용도로 제한되며, 회사 업무용(유급 직원 개발 포함)은 상업적 이용에 해당 |
| 접근 통제 | 공개 / 로그인 | 로그인 (사내 메일 도메인 제한) | 데이터는 공개지만 검색 기록이 영업 대상을 드러냄. 권한 파일만 바꾸면 전환 가능 |
| 검색 기록 저장 | 저장 / 미저장 | MVP 미저장 | 저장 시 사용자·회사명 조합은 영업정보에 해당 |
| 수집 실행 위치 | GitHub Actions / Vercel Cron / 사내 PC | GitHub Actions | 해외 IP 에서 OpenDART 접속 가능 여부 W1 첫날 확인. 막히면 Vercel 함수(서울 리전) |
| 회사채 금융채 포함 | 포함 / 제외 | 트렌드 기본은 제외, 필터로 포함 | 108 신고서는 케이카캐피탈을 일반 회사채에 포함함 → 현업 확인 |
| 회사채 쿠폰 | 민평 방식은 발행조건확정 시점에 쿠폰이 없음 | 확정 가산금리로 표시, 쿠폰은 정기보고서 '채무증권 발행실적'으로 보강 검토 | 호출 수가 많아(회사×보고서) 우선순위 협의 |
| 업무망 접속 | vercel.app 접속 가능 여부 | 확인 필요 | 업무망에서 막히면 인터넷망 PC 사용 또는 사내 배포 경로 협의 |
