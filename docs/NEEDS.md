# 발행시장 트렌드 — 커버리지 RM·RA 니즈와 문제 정의

- 작성: 2026-10-16 · 근거: 커버리지 인터뷰 모음(09-09 공통, 09-09·09-15 SME, 10-13 GI), 이랜드월드 108 DCM 딜 E2E, 레이크머티리얼즈 2CB 메자닌 딜 E2E
- 범위: 이 도구가 다루는 것은 공개 데이터(DART·ECOS)로 할 수 있는 **탐색·제안 준비** 단계다. 신고서 작성·계약서·Book 한도·심사는 사내 데이터라 범위 밖

## 1. 한 줄 문제 정의

RM·RA는 담당 회사(일반 60곳, SME 100~150곳)와 시장의 변화를 DART·본드웹·FnGuide·CIS 에서 손으로 모은다. 그래서 **연락할 이유를 늦게 알고**, **제안서 데이터 페이지(14쪽 중 10쪽 이상)를 매번 새로 만든다**. 이 도구는 공개 데이터만으로 "오늘 누구에게 왜 연락할지"와 "제안서에 넣을 시장 근거"를 한 화면에 준다.

## 3. RM·RA 가 챙겨야 할 공시 (이번에 추가한 것 굵게)

| 묶음 | 공시 | 왜 보나 |
|---|---|---|
| 자금 수요 | **단기차입금 증가결정**, **신규시설투자**, **자기전환사채 만기 전 취득(풋)**, **자기주식 처분결정**, **타인에 대한 채무보증·담보제공** | 차환(회사채·CP 전환), 장기 조달, 메자닌 재발행, 교환사채 전조, 계열·PF 지원 |
| 지배구조·M&A | **최대주주 변경**, **최대주주 변경 수반 주식양수도**, **경영권 변경 계약**, **최대주주 주식담보 계약**, 타법인 지분·영업 양수도, 합병·분할·주식교환 | 인수금융·리파이낸싱, 새 최대주주의 조달 계획 |
| 신용·상장 위험 | **사채 원리금 미지급·기한이익 상실**, **채권은행 관리절차**, **상장폐지 사유 발생·실질심사 대상 결정·감사의견 거절**, **횡령·배임**, 회생·부도·해산·영업정지 | 기존 발행 채권·메자닌 노출 점검, 거래 회피 |
| 자산·실적 | 유형자산 양수·양도, 감자, **매출액·손익구조 30%(대규모 15%) 이상 변동** | 등급·조달 여건 변화 |

다음 후보(아직 안 넣음): 전환가액 조정(리픽싱)·전환청구권 행사(오버행), 풍문·보도 해명(M&A 루머), 단일판매·공급계약(매출 대비 큰 계약 → 운전자금, 이미 수집 중이나 피드 제외), 신용등급 변경(DART 밖, 신평사 공시 별도 수집 필요).

## 4. 범위 밖 (사내 데이터가 필요한 것)

Book·RWA 잔여 한도, 증권신고서 전 회차 업데이트 초안, 계약서 수정 취합, 배정 마스터 → 문서 일괄 생성. 각각 E2E 분석 문서의 1순위 백로그로 별도 진행.

## 5. 확인할 질문 (다음 인터뷰)

1. 관심 회사 목록을 RA 가 실제로 몇 곳 넣는지, 매일 아침 확인 루틴에 들어갈 수 있는지(10-16 SME RM 임동영 대리)
2. '주요 공시' 묶음과 RM 포인트 문구가 현업 용어와 맞는지, 빠진 공시 종류
3. 제안 준비의 같은 등급군 비교 기준(6개월·등급군)이 제안서 관행과 맞는지(GI 노다함 대리)
4. 트랙레코드 CSV 열 구성이 제안서 표와 맞는지
