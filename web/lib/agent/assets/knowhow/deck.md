# 장표 구성 노하우

어떤 장표를 켜고 끌지, 어떤 목차 템플릿을 쓸지 정한다. 장표 순서는 양식에 고정돼 있어 바꿀 수 없다.

## 템플릿

### DK-01 목차 템플릿
- 선택: ① 기본(basic): Ⅰ 발행 제안 + Ⅱ 회사채 시장 동향 + Appendix (기본) ② 간략(lite): 사용자가 짧게·간단히 원할 때, 10장 안팎

## 켜고 끄기

### DK-02 NH 강점 섹션
- 대상: 회사 현황(nh_company)·핵심 경쟁력(nh_core)·IB 업무 범위(nh_scope)·업무 분장(nh_org)·League Table(league)·대표주관 실적(strength)
- 조건: 회사 공모채 발행 횟수
- 선택: ① 2회 이상(리피트 발행사)이면 끔 (기본) ② 첫 공모채 발행이면 켬
- 근거: 리피트 발행사에는 NH 강점 섹션을 넣지 않음 (CJ프레시웨이 2026-03 구성)

### DK-03 미매각 사례 분석 (compare)
- 선택: ① 같은 등급 최근 미매각·일부 미달 사례가 있으면 켬 ② 없으면 끔 (기본)

### DK-04 IR 및 수요예측 전략 (ir)
- 선택: ① 기본 끔 ② 첫 공모채 발행이거나 사용자가 원하면 켬

### DK-05 최근 발행금리 (corp)
- 선택: ① 기본 끔 ② 사용자가 금리 근거를 원하면 켬

### DK-06 CEO MESSAGE (ceo)
- 선택: ① 기본 끔 (대표이사 이름 확인 필요)

### DK-07 자료 없는 장표
- 조건: 장표 목록에서 '자료있음'이 아닌 장표
- 선택: ① 끄고 보고에 이유를 적는다 (기본)

### DK-08 순서 변경 요청
- 조건: 사용자가 장표 순서를 바꾸라고 할 때
- 선택: ① 순서는 양식에 고정이라 바꿀 수 없다고 보고하고, 켜고 끄기로 할 수 있는 것을 제안 (기본)
