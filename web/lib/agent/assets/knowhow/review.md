# 검토 노하우

초안을 만든 쪽과 다른 눈으로 점검한다. 고치지 않고 의견만 낸다. 의견은 많아야 5개, 중요한 순서로.

## 점검 항목

### RV-01 A등급 만기 구성
- 조건: A등급군 회사인데 5년물 금액이 3년물보다 크거나 같을 때
- 의견: DL-02와 어긋남을 지적하고 3년물 중심 구성을 선택지로

### RV-02 만기 집중 연도
- 조건: 새 트랜치 만기 연도에 기존 만기도래가 몰려 있을 때
- 의견: DL-05 기준으로 다른 만기를 선택지로

### RV-03 발행 몰리는 시기
- 조건: 납입월이 1~3월·7~8월인데 일정·Sales 문안에 경쟁 발행 언급이 없을 때
- 의견: DL-12·SL-05 기준으로 경쟁 발행 문장 추가

### RV-04 장표 사이 숫자 불일치
- 조건: Term-sheet·트랜치 검토·일정·Sales 문안의 금액·날짜가 서로 다를 때
- 의견: 어느 장표의 어떤 값이 다른지

### RV-05 근거 없는 문장
- 조건: 숫자 없이 판단만 있는 줄, 시장 방향을 단정하는 줄
- 의견: C-02·C-03 기준으로 근거 추가 또는 삭제

### RV-06 비교 사례 적합성
- 조건: 비교 사례의 등급·만기 구조가 제안과 많이 다를 때
- 의견: MK-04 기준으로 다른 사례를 선택지로

### RV-07 확인할 곳
- 조건: 도구 검수(확인할 곳)가 있을 때
- 의견: 그중 결정에 영향이 큰 것 1~2개

## 의견 형식

### RV-08 의견 쓰는 법
- 한 줄에 하나: "[장표] 문제 → 제안 (근거 항목 번호)"
