# 확인할 곳 (검수)

`dcm_check` 가 돌려주는 '사람이 정하거나 확인할 곳'. 파일(PPTX·PDF)에는 표시되지 않는다.

| 종류 | 뜻 | 예 |
|---|---|---|
| 입력 확인 | 기본값 그대로인 조건 | 신용등급·만기·발행금액·금리 밴드·납입일·수수료, 뒷표지 연락처 없음 |
| 판단 확인 | 규칙이 만든 판단 문장 | Term-sheet 발행 시기·구조 문장, 트랜치 구성 판단 |
| 데이터 확인 | 대체 데이터·이상값 | 민평 대신 ECOS 금리, 일별 대신 월말 금리, 사례 표 이상값 |
| 갱신 필요 | 오래된 시장 자료 | 금통위·FOMC 요약, 증권사 전망, 공개 전망표가 최근 회의보다 오래됨 |

## 알리는 방법

- 처음 초안과 큰 변경 뒤에만: 개수 + 종류별 개수 + 가장 중요한 3개(입력 확인 > 판단 확인 > 갱신 필요 > 데이터 확인 순).
- 사용자가 값을 알려 주면 해당 행동으로 반영한다(예: 수수료 → `fee`).
- 데이터 확인·갱신 필요는 사용자가 고칠 수 없는 것이 많다. "사내 연계 필요" 또는 "공개 자료 갱신 필요"라고만 말한다.
