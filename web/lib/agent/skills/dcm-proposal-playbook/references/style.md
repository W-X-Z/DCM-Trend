# 문체·표현

## 장표 문안

- 개조식, 명사형·간결체: "~집중", "~제안", "~필요", "~확보", "~수준", "~진행".
- 한 줄 90자 이내, 장표 요약은 3~5줄.
- 각 줄은 '근거(숫자) → NH투자증권 판단·제안' 순서. 핵심 구절 1~2개만 **굵게**.
- 숫자는 데이터에 적힌 표기 그대로(예: 1,500억원, 5.00:1, '26.09). 새로 계산한 비율·합계를 만들지 않는다.
- 기관 실명은 데이터에 기관명이 있을 때만. 지금 공개 데이터는 투자자 구분(운용사·증권사·연기금·은행·보험 등)까지만 있다.
- 금지: 시장 방향 예측("금리 하락 예상"), 확실·보장 표현("반드시", "확실히"), 근거 없는 수식어("최고의", "압도적인").
- 시장 의견은 출처를 밝힐 때만: "○○증권에 따르면 …", "한국은행 통화정책방향 결정문에 따르면 …".

## Sales 전략 장표에 쓰는 것

1. 이 회사 수요예측의 주력 투자자군과, 같은 등급 대비 약한 투자자군
2. 그 근거로 마케팅할 투자자군과 방법(IR·NDR·리테일 세일즈 등)
3. 제안 만기 구조와 투자자군 성향의 연결(예: 장기물은 보험·연기금, 단기물은 운용사·증권사)
4. 수요예측 일정상 경쟁 발행이 있으면 선제 확보 방안

사실로 뒷받침되는 것만 쓴다.

## 사용자에게 하는 말 (채팅)

- 존댓말(~요), 짧게. 무엇을 바꿨는지 한두 문장.
- 내부 명령·파일 경로 대신 사용자가 아는 말(장표 이름, 조건 이름)로.
- 모르는 값은 모른다고 하고, 필요한 데이터(예: "민평 4사 연계 필요")를 말한다.
