# 데이터 (Data)

## 두 종류만 있다

- **외부 데이터**: 누구나 접근 가능한 공개 자료. DART(증권신고서·정정신고서·발행실적보고서), 한국은행 ECOS·통화정책방향, 미 연준 FOMC 성명·SEP, 관공서 공휴일, 금융감독원 일정, 증권사 공개 리포트·기사 요약, Discussion Material(DM) 판(시장 동향 공개 자료 묶음).
- **내부 데이터**: NH 자체 자료와 구독 데이터. **지금은 연계되지 않았다(미연계).** 민평 4사(개별·등급민평, 민평 커브, 스프레드 시계열), NH 리서치(전망표·회의 리뷰·DM 원본), NH 수요예측 북(기관별 참여·배정), FnGuide(리포트 취합), 본드웹(발행 통계).

## 어디서 받나

- 엔진 `dcm_load` 가 프로토타입 데이터(`/api/deck/data` 와 같은 것)를 한 번에 받는다. 기준일(`asof`)은 결과에 있다. DART·ECOS 원천은 매 영업일 수집된 것을 쓴다.
- 장표별로 무엇을 썼는지: `dcm_report` (외부: 데이터·출처·기준일·쓰인 장표 / 내부: 미연계 목록과 쓰일 장표).
- 문안의 근거 숫자: `dcm_facts` (사실 묶음). 사용자에게 근거를 말할 때는 여기 있는 숫자와 출처만.

## 질문별 답하는 법

| 질문 | 할 일 |
|---|---|
| "이 트랜치 구조를 제안한 근거는?" | `dcm_facts` 의 같은 등급 만기 비중·회사 만기 분포·최근 회차 경쟁률을 인용. 출처(DART)와 기준일을 함께 |
| "이 숫자 어디서 나왔어?" | `dcm_report` 에서 그 장표의 데이터·출처를 찾아 답한다 |
| "민평 기준으로 밴드 다시 봐줘" | 민평 4사는 미연계라 지금은 개별민평 수치를 넣을 수 없다고 말하고, 밴드 bp 값만 바꾸는 것은 가능하다고 안내 |
| "NH 리서치 전망으로 바꿔줘" | NH 리서치 전망표는 미연계. 지금 덱은 공개 전망표(오래되면 의견만)라고 설명 |
| "기관별로 누가 들어왔어?" | 공개 데이터는 투자자 구분(운용사·증권사·연기금·은행·보험 등)까지. 기관별은 NH 수요예측 북 연계 필요 |

## 내부 데이터가 없을 때 엔진이 하는 것

| 장표 | 처리 |
|---|---|
| 제안 Term-sheet | 밴드 비고에서 민평 수치 제외 |
| 트랜치 검토 | 민평 커브 근거 제외, 금리 표는 ECOS |
| 금리 동향 | 발행사 등급 스프레드 대신 AA-·BBB- 스프레드 |
| 기준금리 및 국고채 금리(전망) | 공개 전망표. 발표 뒤 금통위·FOMC 가 있었으면 표·수치를 빼고 의견만 |
| 회사채 금리(전망) | NH 등급별 전망표가 없으면 장표 생략 |
| 증권사별 전망 | 공개 리포트·기사 요약(하우스 수가 적을 수 있음) |
| 회사채 수요예측 결과 | 수요예측 전일 spread 열 숨김 |

## 지키는 것

- 내부 데이터 값을 짐작하거나 지어내지 않는다.
- 사용자가 붙여 준 고객사 비공개 정보는 덱·기억·암묵지에 남기지 않는다(프로토타입은 공개 데이터 전용).
- 데이터 기준일이 오래되었으면(예: 금통위 요약이 최근 회의 이전) `dcm_check` 의 '갱신 필요'로 알린다.
