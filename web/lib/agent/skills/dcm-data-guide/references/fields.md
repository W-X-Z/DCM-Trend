# 엔진 데이터(data.json) 주요 칸

`dcm_load` 가 받는 회사 데이터의 칸. 보통은 `dcm_state`·`dcm_facts`·`dcm_report` 로 충분하다.

| 칸 | 내용 | 출처 |
|---|---|---|
| `asof` | 데이터 기준일 | — |
| `company` | 회사명·시장·신용등급·등급군·직전 회차·공모채 발행 횟수 | DART |
| `own[]` | 회사 공모채 회차(최근순): 수요예측일·최초 신고·발행금액·경쟁률·밴드·확정 금리·대표주관·트랜치별 결과·투자자 구분별 참여(`byType`) | DART 증권신고서·정정신고서 |
| `peers[]` | 같은 등급군 최근 12개월 회차(같은 형식). `flag` 가 있으면 비교군 제외(보증·담보부 추정, 공기업) | DART |
| `maturities[]` | 회사 공모채 만기도래(일자·회차·금액·쿠폰·만기 개월·주관사) | DART 발행 내역 |
| `combos[]` | 같은 등급 만기 구조별 발행 건수·비중·경쟁률·증액 비중 | DART |
| `league` / `leagueAll` | 대표주관 실적(같은 등급 / 전체) | DART |
| `rates[]` | 금리 최신값과 1·3개월·1년 변화(기준금리·국고·회사채 AA-·BBB- 등) | ECOS(없으면 조사 값) |
| `series[]` / `daily[]` | 금리 월말·일별 시계열 | ECOS |
| `policyHistory` | 한국·미국 정책금리 변경 이력 | 한국은행·미 연준 |
| `policy` | 최근 금통위·FOMC 결정·표결·핵심 포인트 | 한국은행·미 연준 공식 발표 |
| `forecast` | 공개 금리 전망표(하우스·발표일·분기별 값)와 주제별 의견 | 증권사 공개 리포트 |
| `views[]` / `usViews[]` | 증권사별 국내·미국 기준금리 전망 | 공개 리포트·기사 |
| `marketNotes[]` | 최근 60일 크레딧·국고채 시장 의견 | 증권사·언론(출처 URL 포함) |
| `dm` | 이번 달 Discussion Material 판(시장 동향 장표 원문·차트) | DM 판(공개 자료 기준) |
| `holidays` · `events` | 공휴일, 금통위·FOMC·정기보고서 기한 | 관공서·한국은행·미 연준·금감원 |
| `pipeline[]` | 수요예측 예정 일반 공모 회사채(신고서 제출~납입 전) | DART 증권신고서 |
| `recentIssues[]` · `issues[]` · `market[]` | 등급별 최근 발행 결과·발행 규모 | DART 정정신고서·발행실적 |
| `maturityByGrade` | 등급별 월별 만기도래 | DART 발행 내역 |
| `leagueYearly[]` | 연간 대표주관 실적 | DART |
| `fee` | 직전 회차 인수·대표주관 수수료 | DART 증권신고서 |

없는 칸(예: 민평, 기관별 수요예측)은 내부 데이터라 아직 없다.
