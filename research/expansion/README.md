# 사업 확장 기업

최근 1년 동안 **공장·설비 증설, 부지·사업장 매입, 기업·사업 인수**를 결정한 기업을 DART 공시에서 골라 둔 목록입니다.
개인 투자 아이디어 분석용 자료이며, 매수·매도 판단 근거가 아니라 **살펴볼 후보를 좁히는 출발점**으로 씁니다.

같은 데이터와 기준을 업무용 화면(발행시장 트렌드 '사업 확장' 탭, https://ib-deal-agent.vercel.app/expansion)에서도 씁니다.

## 무엇을 '사업 확장'으로 보나

공시 종류만으로 고르지 않고, 공시에 적힌 **목적·대상 글**을 읽어 나눕니다. 예를 들어 같은 '유형자산 양수'라도 공장 부지면 확장, 임대 수익용 빌딩이면 제외합니다.

| 원천 공시 | 확장으로 보는 경우 | 빼는 경우 |
|---|---|---|
| 신규시설투자 (거래소 공시, 원문을 읽음) | 공장·라인·설비·선박·항공기·데이터센터 등. 사옥·R&D센터는 '연구·업무시설', 부지 개발·호텔·매장은 '부지·사업장' | 임대·투자 수익 목적, 사옥 임차 |
| 유형자산 양수 (주요사항보고서 상세 API) | 생산·공장·설비·물류·산업단지 → 생산·설비 / 부지·용지·사업장 → 부지·사업장 / 사옥·연구시설 → 연구·업무시설 | 임대·투자 수익, 재무구조 개선 |
| 타법인 지분 인수 (주요사항보고서 상세 API) | 인수 후 지분 30% 이상 또는 경영권 확보, 자회사 공장 설립 출자 | 단순·재무적 투자, 30% 미만 소수 지분, 계열사 지배력 강화·지배구조 정리 |
| 영업양수 (주요사항보고서 상세 API) | 모두 | – |

확장 유형은 네 가지입니다.

| 유형 | 예 |
|---|---|
| 생산·설비 증설 | 공장 신증설, 생산라인, 설비·선박·항공기 도입, 물류센터, 데이터센터 |
| 부지·사업장 확보 | 공장 부지·용지 매입, 부지 개발, 매장·호텔·병원 등 사업장 |
| 인수·신사업 | 경영권 인수(지분 30% 이상), 영업양수, 신사업 진출 목적 인수 |
| 연구·업무시설 | 사옥·R&D센터 매입·신축 (확장 신호로는 가장 약함) |

### 그 밖의 규칙

- **정정공시**: 같은 결정(회사·공시 종류·결의일·대상)은 가장 늦게 접수된 정정본의 금액·목적을 씁니다. 마지막 접수본이 철회면 뺍니다.
- **진행 중**: 결정은 1년보다 전이지만 최근 1년 안에 금액·기간을 정정한 투자입니다. `최근 1년 새 결정` 열이 `진행 중`으로 표시됩니다.
- **중복**: 지주사가 낸 '자회사의 주요경영사항' 공시가 상장 자회사의 공시와 같으면 지주사 쪽을 뺍니다.
- **제외 기업**: 금융사(금융지주·은행·증권·보험·재보험·캐피탈·카드·자산운용·벤처캐피탈·저축은행), 리츠, 스팩. 업종코드를 아직 모으지 않아 회사 이름으로 거릅니다.
- **결정 후 조달 없음**: 첫 확장 결정 이후 DART에 공시된 조달(공모 회사채, 메자닌, 유상증자, IPO)이 없다는 뜻입니다. 은행 차입·자체 자금은 공시되지 않으므로 '돈이 필요하다'는 뜻은 아닙니다.

| 가장 큰 결정 | 금액이 가장 큰 공시의 종류·금액·목적 |
| 최근 1년 공시 조달 | 최근 1년 공모 회사채·메자닌·유상증자·IPO (최대 5건) |

## 원천과 범위

- **출처**: 금융감독원 OpenDART (공시 목록, 주요사항보고서 상세 API, 공시 원문)
- **기간**: 결정일 기준 최근 365일. 거래소 공시 목록은 2025-10부터, 상세 API는 2025-10부터 모았습니다.
- **처리 위치**: 이 저장소의 수집기(`ingest/`)가 Supabase에 쌓고, 분류는 DB 뷰가 합니다.
  - 분류 규칙: `supabase/migrations/*_expansion_views*.sql`의 `core.v_expansion_events` (마지막 파일이 현재 규칙)
  - 화면·내보내기용: `mart.v_expansion_events`, `mart.v_expansion_companies`
  - 규칙 테스트: `tests/run.mjs`의 '사업 확장' 항목 (`npm test`)

### 알려진 한계

- '타법인주식및출자증권**취득**결정', '영업양수결정'처럼 상세 API가 없는 형식의 공시(연 70건 안팎)는 빠져 있습니다.
- 주가·시가총액이 없습니다. 규모는 공시에 적힌 자기자본·자산총액 대비 비율로만 봅니다.
- 금액은 공시된 총 투자액이며 실제 집행 시점·금액과 다를 수 있습니다.
- 분류는 글자 규칙이라 애매한 공시는 틀릴 수 있습니다. 판단 전에 `events.csv`의 원문 링크로 확인하세요.

## 갱신

- **자동**: GitHub Actions `export-expansion`이 매주 월요일 08:20(KST)에 `data/`를 다시 만들고 바뀐 내용이 있으면 커밋합니다. Actions 탭에서 수동 실행도 됩니다.
- **직접 실행**:

  ```bash
  SUPABASE_URL=https://<project>.supabase.co SUPABASE_KEY=<읽기 키> node research/expansion/export.mjs
  ```

  `mart` 뷰만 읽으므로 읽기 전용(anon) 키로 충분합니다.
- **최신 화면**: https://ib-deal-agent.vercel.app/expansion (유형·시장·금액·조달·결정 시점 필터, CSV 내려받기)
